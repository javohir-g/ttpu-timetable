# EduPage → Telegram расписание (TTPU)

Расписание с ttpu.edupage.org в Telegram. Без зависимостей — только стандартная библиотека Python.

Два режима:

| Файл | Что делает |
|---|---|
| `universal_bot.py` | **Универсальный бот** — любой студент или преподаватель настраивает себя сам через /start |
| `bot.py` | Одноразовая отправка расписания одной группы (для планировщика задач) |

## Универсальный бот

1. Создай бота у [@BotFather](https://t.me/BotFather), возьми токен.
2. Впиши токен в `config.json` → `telegram_bot_token`.
3. Запусти:

```
python universal_bot.py
```

Бот работает, пока запущен скрипт (long polling). Каждый пользователь пишет боту сам:

- `/start` → выбирает «🎓 Я студент» (направление → группа) или «👨‍🏫 Я преподаватель» (поиск по фамилии)
- `/today`, `/tomorrow`, `/week` — расписание
- `/change` — сменить группу/преподавателя

Настройки пользователей сохраняются в `users.json` и переживают перезапуск.
Расписание кэшируется 30 минут, свежая неделя подхватывается автоматически.

Студент видит: время, предмет, преподавателя, аудиторию, подгруппу.
Преподаватель видит: время, предмет, группы, аудиторию.

### Автозапуск при старте Windows

```
schtasks /Create /TN "EdupageBot" /TR "pythonw \"C:\Users\User\Desktop\qbit v1.0\edupage-telegram-bot\universal_bot.py\"" /SC ONSTART
```


## Напоминания о парах

Бот умеет писать перед началом пары. Время выбирает сам пользователь командой
`/remind`: 5, 10, 15, 30 или 60 минут либо «Off». По умолчанию выключено.

Проверка времени живёт в главном цикле бота — он просыпается не реже чем раз
в 50 секунд, поэтому отдельный планировщик не нужен. Время считается в поясе
Ташкента (UTC+5, перевода часов нет), а не по часам машины: на хостинге в другом
поясе напоминания иначе уехали бы на часы.

Пропущенное не догоняется: если бот лежал, напоминание о паре, которая уже идёт,
только путало бы.

## Мини-апп раздаётся тем же процессом

Бот поднимает простой веб-сервер на порту из переменной `PORT` (её задаёт
хостинг) и отдаёт папку `miniapp`. Страница, данные и service worker уходят
с заголовком `no-cache`, иначе обновление не доехало бы до телефона; иконки
и анимации живут сутки.

Он же пересобирает `miniapp/data.json` тем же сборщиком, что и сборки GitHub:
сразу при запуске (свежий контейнер иначе отдал бы файл из репозитория,
которому может быть несколько дней) и дальше раз в `DATA_REFRESH_MIN` минут.

Публикация на GitHub Pages остаётся запасным адресом: она ничего не ломает
и обновляется своим расписанием раз в шесть часов.

## Хостинг на Railway

Напоминания приходят, только пока бот запущен, поэтому он живёт на Railway,
а не на домашнем компьютере.

Что нужно в проекте Railway:

1. **Источник** — этот репозиторий, ветка `main`. Сборщик Nixpacks подхватит
   `requirements.txt` и `railway.json` (команда запуска уже прописана там).
2. **Домен**: Settings → Networking → Generate Domain. Тот же сервис раздаёт
   мини-апп, поэтому адрес нужен, и он же идёт в `MINIAPP_URL`.
3. **Переменные**:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather;
   - `MINIAPP_URL` — выданный домен, например `https://ttpu.up.railway.app/`;
   - `DATA_DIR` — `/data`;
   - `EDUPAGE_SUBDOMAIN` — `ttpu` (необязательно, это значение по умолчанию);
   - `DATA_REFRESH_MIN` — как часто пересобирать расписание, минут (по умолчанию 30);
   - `SERVE_MINIAPP` — `0`, если мини-апп раздаёт кто-то другой.
4. **Том (Volume)** — подключить к сервису с путём `/data`. Без него файловая
   система контейнера очищается при каждом развёртывании, и список пользователей
   вместе с настройками напоминаний пропадёт.

Токен в репозиторий не кладём: `config.json` в `.gitignore`, на хостинге
настройки берутся из переменных окружения.

Важно: Telegram разрешает опрашивать обновления только одному процессу. Если бот
запущен и на Railway, и локально, оба получат ошибку 409 — локальный нужно
остановить.
## Одноразовая отправка (bot.py)

Для ежедневной авторассылки одной группе в фиксированный чат:
заполни `class_name`, `telegram_bot_token`, `telegram_chat_id` в `config.json` и:

```
python bot.py today       # сегодня
python bot.py tomorrow    # завтра
python bot.py week        # неделя
python bot.py --dry-run week   # в консоль, без отправки
```

Ежедневно в 7:00 через планировщик:

```
schtasks /Create /TN "EdupageTimetable" /TR "python \"C:\Users\User\Desktop\qbit v1.0\edupage-telegram-bot\bot.py\" today" /SC DAILY /ST 07:00
```
